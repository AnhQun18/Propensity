# Công cụ tác giả

`sync_preparation_notebook.py` đồng bộ các cell định nghĩa từ `src/propensity_data/`
sang `notebooks/02_data_preparation.ipynb`; dùng `--check` để chỉ so sánh văn bản.
Công cụ không chạy notebook, không import pipeline và không đọc raw.

Trong đợt thay đổi này, công cụ và kiểm thử được viết để sử dụng sau, chưa chạy
trên máy hiện tại theo yêu cầu người dùng.
